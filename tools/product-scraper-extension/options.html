Quick setup recap

  1. One-time, server side (ships with the repo): apply funnel/schema.sql to D1 and deploy the funnel app — full commands in this folder’s README.md.
  2. Paste the deployed app’s URL above and Save settings — allow the permission prompt so the extension may reach that site.
  3. Sign in to the Command Center in this browser (your own founder email + password).
  4. Test connection — it should report you’re signed in and the captures API is reachable.
  5. Captured rows appear on /internal/captures (SC-19 · Product Captures), attributed to whoever is signed in.
