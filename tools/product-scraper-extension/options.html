Quick setup recap

  1. Create (or open) the team Google Sheet.
  2. In the sheet: Extensions → Apps Script, delete the placeholder code, paste the contents of apps-script/Code.gs from this extension’s folder, and save.
  3. Deploy → New deployment → Web app → Execute as Me → Who has access Anyone → Deploy, then authorize when Google asks.
  4. Copy the /exec URL into the field above, save, then click Send test row — a TEST row should appear in the sheet’s Products tab.
  5. Any time you edit Code.gs later: Deploy → Manage deployments → ✏️ → Version: New version. The old URL keeps serving old code until you do.
